# Education Data Insights for Decision Support

## Overview
This project analyses education-related data to extract actionable insights that support evidence-based decision-making in the public sector.

The aim is to demonstrate practical data analysis skills relevant to national organisations such as SDAIA.

## Objectives
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualisation of key trends
- Insights and recommendations for decision-makers

## Tools
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Key Insights
- Student enrollment increased after 2020.
- Graduation rates improved over time.
- Public spending increased consistently.
