# National Data Analysis Project

## Overview
This repository contains data analysis projects focusing on public-sector and national datasets.
The goal is to extract insights that support evidence-based decision-making.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn
- Jupyter Notebook

## Objectives
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Visualisation of key insights
- Policy and decision-support recommendations
